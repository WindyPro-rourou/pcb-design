# 叠层与阻抗控制（IPC-2221 §6.4 + 材料）

## 1. 四种基本传输线

- **A. Microstrip（微带线）**：导体位于两种介质界面，一面对空气(εr=1)、一面对基材(εr>1)，参考平面在基材另一侧。三面接触低 εr、一面接触高 εr。
- **B. Embedded Microstrip（埋微带）**：同上但导体完全埋入高 εr 介质中。介电厚度 ≥0.025mm 时按 IPC-D-317 求有效 εr；<0.025mm 时有效 εr 介于空气与体材料之间。
- **C. Symmetric Stripline（对称带状线）**：导体完全包围在均匀介质中，居中于两参考平面之间。EMI/串扰更小，阻抗更低、电容更大。
- **D. Dual / Asymmetric Stripline（双/非对称带状线）**：一或多层导体非对称地位于两参考平面之间。

## 2. 阻抗与电容公式（标准给出，英制）

**Microstrip**：`Z0 = 87/√(εr+1.41) · ln[5.98h/(0.8w+t)]`（Ω）
`Tpd = √εr / c`（ps/inch，c=3×10^8 m/s）；`C0 = Tpd / Z0`（pF/inch）
其中 h=介质厚、w=线宽、t=线厚（inch），适用 w/h<1。

**Symmetric Stripline**：`Z0 = 60/√εr · ln[1.9(2H+T)/(0.8W+T)]`（Ω），`C0 = 1.41εr / ln[3.81H/(0.8W+T)]`（pF/in），适用 W/H<2。H=到单侧地平面的距离。

**Dual(Asym) Stripline**：`Z0 = 80/√εr · ln{1.9(2H+T)/(0.8W+T) · [1 − H/(4(H+C+T))]}`，H=离最近电源平面高度、C=信号平面间距。两信号层通常正交布线以减小层间串扰。

> 高速布线参考 IPC-D-317（高速设计）、IPC-D-330（设计手册）。

## 3. 叠层顺序（关键实践）

- 信号层**对称**分布于地/电源平面两侧；参考平面**不要随意分割**。
- 相邻信号层若无地/电源平面隔开，**正交(垂直)布线**降低层间串扰。
- **4 层**（配 6-5D 双带线）：`Signal / Plane(GND) / Plane(PWR) / Signal`。
- **6 层 A（首选，阻抗全程匹配）**：`S1 / P1 / S2 / S3 / P2 / S4`。
  B（较差）：`S1 / S2 / P1 / P2 / S3 / S4` —— S1、S4 阻抗明显高于 S2、S3。
- 电源与地**相邻成对且尽量宽**；高频下二者近似同一平面。
- 特殊高频线可"埋"在平面间做成"类同轴(coaxial type)"，两侧过孔按约 2.54mm 间距排布。
- 电源/地连接器引脚沿板边均匀分布作 AC 参考。

## 4. 电容 / 电感 / 去耦

- 微带/带状线单位长度电容曲线见标准 Figure 6-6 / 6-7（1oz 铜、不同介质厚度对地）。
- 单次交叉(crossover)电容极小（约零点几 pF），交叉越多叠加越多：`Cc = X·εr·(l+0.8h)(W+0.8h)/h`，X=0.0089(mm) 或 0.225(in)，l≥0.5h、W≥0.5h。
- 去耦电容**引线尽量短、贴近 IC**，否则自感过大导致开关噪声；高 I/O 封装可把电容内置。
- **过孔越小寄生电感越低**（0.5mm→0.3mm 明显改善）。
- 相邻且贴近的电源/地平面可提供高频去耦电容，节省去耦电容占位。
