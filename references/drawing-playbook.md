# Agent 画板作战手册（从需求到可打样）

> 面向"会用嘉立创 EDA 工具自动画板"的 AI Agent：把前面的标准/工具/经验串成**可执行步骤 + 每步自检关卡**。
> 工具调用细节见 `eda-automation-api.md`；布局/布线深挖见 `eda-board-process.md`、`eda-deep-routing.md`；
> 数值标准见 `ipc-*`；制造坑见 `manufacturing-dfm.md`。**照此顺序做，能少返工。**

---

## 0. 开工前先问清（缺就问，别猜）
- 用途与可靠性等级(Class 1/2/3)、是否需要认证。
- 板尺寸上限 / 层数预算 / 成本档（如嘉立创免费档：≤100×100mm、2 层、1.6mm）。
- 电源轨与电流（决定线宽/铺铜/层数）、关键接口与器件（MCU/电源/连接器/屏/无线）。
- 机械约束：外壳、安装孔位置与内缩、端口朝向、按键/屏幕遮挡、天线可用区。
- 特殊：阻抗要求(单端/差分)、高速/射频、散热、要过的测试。

## 1. 定结构（先定，后画）
- 层数：简单低速 2 层；有高速/阻抗/BGA/电源完整 → 4 层（S-G-P-S）；更复杂 6 层。
- 叠层表：写清每层功能、材料、介质厚度、铜厚；控阻抗再写目标值(±10%)。
- 先把 IPC 设计值定好（间距/环宽/线宽/孔径），设计值 ≥ 验收下限（见 `electrical-clearance-current.md`、`holes-lands-vias.md`）。

## 2. 原理图阶段（先通再转 PCB）
- 放件**四步**：`lib_Device.search(完整型号)` → `sch_PrimitiveComponent.create` → `modify({designator, otherProperty})` → `getAllPinsByPrimitiveId`（位号不自动分配）。
- 连线用 `sch_PrimitiveWire`（正交折线）；电源/地用 `createNetFlag('Power'|'Ground', name, x, y)`（**导线本身不定义网络**）。
- 自检 **G0**：`eda_save` → 等 8~10s → `eda_sch_drc(check(true,false,true))` 无错 + `eda_get_netlist` 连接符合预期。
- 复杂页 create 慢（80×）：在**新空页/新工程**批量放件，或走 `eda_task`；单次放 20~25 个为宜。

## 3. 布局 SOP（先固定件，后可动件）
1. **机械固定件先落位**：连接器、按键、旋钮、屏排母、TF/USB 座、安装孔——按外壳坐标定位；端口朝向对侧壁开口。
2. **按功能分区**，单向信号流：电源 → MCU → 接口/驱动；模拟/数字/RF 分区，RF/天线留净空禁铜区。
3. **就近原则**：旁路/去耦电容贴电源脚；晶振紧贴 MCU 且下方包地；反馈取样线短；复位/启动电阻就近。
4. **电流与热**：大电流走宽线/铺铜；发热件远离热敏、留散热铜/过孔。
5. **均衡摊开**：可动件按网格蛇形铺开、保持功能簇相邻；按 x/y 分 5 带统计**任何一带为 0 = 有空区**，继续摊。
6. **间距即靶点**：DRC 的 `SMD Pad to SMD Pad / Hole to SMD Pad / Board Outline to Pad` **都是布局问题，挪件不改线**。
- 自检 **G1**：间距类 DRC 大幅下降/清零；分带无空区；固定件与外壳 3D 无干涉。

## 4. 布线 SOP（顺序很重要）
1. **先地/电源，再关键信号，最后普通信号**：先铺 GND（双层八角环形地线/铺铜后 `rebuildCopperRegion`），电源主干宽线；再布时钟/差分/高速/复位，最后其它。
2. **走线纪律**：45°/圆弧，**禁直角与锐角**（酸角/反射）；走线短、少绕；参考平面连续、不跨分割。
3. **差分/高速**：等长、等距、等宽；需要时包地/加间距；时钟远离接口与板边；必要时串阻/端接。
4. **过孔纪律**：能少不多；电源/地多打过孔且就近；盘中孔必塞孔研磨；过孔外径/孔按板厂能力（如 0.3/0.5mm）。
5. **载流**：按温升查线宽（`electrical-clearance-current.md`）；大电流用宽线/铺铜/多过孔。
6. **自动布线**：原生 `autoRouting` **必须分批(3~5 网/批, keep, 45°)**（900s 硬上限，超时不留结果）；追求"像人画的"用**转向罚分路由器** `scripts/smart_route.js`（grid10/turn140/viaCost7000），失败降 maskPad 12→10。
- 自检 **G2**：非 GND 每网络 1 连通域、GND 全 1 域、**孤儿铜 0**、飞线清零（用 `net_check.js`/`gnd_solver.js`，别信软件"未布线"计数）。

## 5. 归零与制造检查
- 自检 **G3（DRC）**：每次改铜 → `rebuildCopperRegion` → `save` → `pcb_Drc.check(true,false,true)`；填充过期会伪造上千条错误且 DRC 巨慢（`minDistance===0` 判假错）。目标：只剩网表同步提示。
- 自检 **G4（DFM）**：线宽/线距/孔径/环宽/板边距 ≥ 板厂能力并留余量；多层给叠层表；盘中孔/盖油/背钻标注；拼板 V-cut 同层直线 / 工艺边 ≥5mm / ≥3 Mark（见 `manufacturing-dfm.md`）。
- 自检 **G5（交付）**：`eda_export` 出 Gerber/BOM/坐标 + `eda_trace` 截图；3D 干涉；Gerber 逐层核对（别用磁盘旧文件）；对象数量符合预期。

## 6. "画坏了" → 修正对照
| 现象 | 多半是 | 修正 |
|---|---|---|
| 大量 `SMD Pad to Pad`/`Hole to Pad` | 布局太挤 | 挪可动件、摊开（回 §3） |
| `Track to Via` / 线擦过孔 | 过孔没做可行性检查 | 过孔单独判间距；用 `smart_route` 的 viaAllowed |
| 铺铜 DRC 上千条、DRC 很慢 | 填充过期 | `rebuildCopperRegion`+save 再 DRC |
| 飞线"清零"但实物不通 | 空网络焊盘被忽略/终点未落焊盘 | 跑 `floating_pad_audit.js`；端点补 10~25mil 短线落焊盘中心 |
| 自动布线是"阶梯/多股平行" | 用了普通最短路 | 转向罚分路由器 + 阶梯合并(45°) |
| 板厂打回 | DFM 红线 | 见 `manufacturing-dfm.md` 十大坑 |
| 高频/干扰 | 直角、参考平面断裂、时钟靠接口 | 45°、平面连续、分区隔离 |

## 7. 迭代原则（agent 自控）
- **小步改 → 立即验证 → 再改**；每改铜必重铺再 DRC；先布局后布线、先地后信号。
- 承认自动化天花板：收敛常靠"补过孔可行性检查""空网络焊盘审计"这类根因，而非无限调参。
- 每轮大改后**重新导出 Gerber 并核对**；随时 `eda_snapshot` 留档、`eda_trace` 截图。

## 8. 开工提示词骨架（可直接套）
> 目标：画一块 <尺寸/层数> 板，Class <n>，电源 <轨/电流>，接口 <…>，外壳约束 <…>。
> 先定叠层与设计规则，按 IPC 取值；原理图放件→连线→ERC/网表；布局先固定件再摊开；
> 先地/电源后关键信号；45°，差分等长；自动布线分批或转向罚分；每阶段跑自检 G0~G5；
> 最后出 Gerber/BOM/坐标 + 截图核对。遇到 DRC 上千条先重铺铺铜。
