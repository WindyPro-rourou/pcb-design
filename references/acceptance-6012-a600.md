# 验收：IPC-6012E 性能规范（2020 中文全文）+ IPC-A-600G 外观判据（全文）

> **IPC-6012E-CN《刚性印制板的鉴定及性能规范》(2020, 76 页, 全文)** —— 性能/鉴定数值；
> **IPC-A-600G《Acceptability of Printed Boards》(2004, 140 页, 全文)** —— 外观/切片"目标/合格/不合格"判据。
> 两者配套：**6012 定"要求值"，A-600 给"怎么看"**；分 Class 1/2/3 判。冲突按文件优先级（合同>主图>性能规范>A-600）。
> 数值均为标准原文（µm 与 µin 并存；本文取 µm 为主）。

# Part 1 · IPC-6012E 关键验收数值

## 1.1 最小环宽（表 3-9）

| 特征 | Class 1 | Class 2 | Class 3 |
|---|---|---|---|
| **外层镀覆孔** | 破环≤180°（连接处减量≤3.5.3.1） | 破环≤90°（连接处减量≤3.5.3.1） | **最小环宽 50 µm**（孤立缺陷处可再减 20%） |
| **微导通孔捕获连接盘** | 破环≤180° | 破环≤90°，连接处≥50µm或最小线宽较小者 | **不得有任何破环** |
| **内层镀覆孔** | 允许破环（连接处减量≤3.5.3.1） | 允许 90° 范围破环 | **最小环宽 25 µm** |
| **微导通孔目标连接盘** | 180° 破环可接受 | 180° 破环可接受 | **不得有任何破环** |
| **外层非支撑孔** | 破环≤90° | 破环≤90° | **最小环宽 150 µm**（孤立处可再减 20%） |

- C1/C2 若客户禁用填角/泪滴盘或未采用，连接盘-导体连接处**最小环宽 25µm**。
- 破环定义与"导体-连接盘交界减量"见 3.5.3.1（对应 A-600 的线宽减少 20%/30% 限值）。导体最小侧向间距按 3.5.2。
- **设计仍按 IPC-2221 取更宽（内0.03/外0.05/非支撑0.15mm），别压到上述验收下限。**

# Part 2 · IPC-A-600G 外观判据（外部/切片）

判据分 Class 1/2/3，每项给 **目标 / 合格 / 不合格**；"工艺指示(Process Indicator)"瑕疵允许可交付。

## 2.1 关键验收数值
| 特征 | Class 3 | Class 2 | Class 1 |
|---|---|---|---|
| 外部环宽—支撑孔 | ≥0.050 mm | 90° 破环允许 | 180° 破环允许 |
| 外部环宽—非支撑孔 | ≥0.15 mm | 90° 破环允许 | 90° 破环允许 |
| 内层环宽(切片) | ≥0.025 mm | 破环允许 | 破环允许 |
| 线宽减薄(缺陷处) | ≤20%（单处≤10%长或13mm） | ≤20% | ≤30%（单处≤25mm） |
| 线间距缩减(局部) | ≤20% | ≤30% | ≤30% |
| 孔铜空洞(切片) | ≤1个/板,≤5%板厚,内层界面不可,≤90° | 同 C3 | ≤3个/板 |
| 芯吸 Wicking | ≤80 µm | ≤100 µm | ≤125 µm |
| 翘曲 Bow&Twist | SMT ≤0.75% / 其他 ≤1.50% | 同左 | 同左 |

\* 破环在"焊盘-线交界"时线宽不得减薄 >20%(C2)/>30%(C1)，交界宽 ≥0.05mm 或最小线宽之较小者。

## 2.2 外部可观察（第2章）要点
- 板边毛刺：粗糙但不散边、无松脱毛刺；缺口/晕圈侵入 ≤50% 边-导体距离或 ≤2.5mm(取小)。
- 基材：织纹外露/手感、暴露或扰动纤维、表面针孔空洞；白斑/微裂/分层起泡/异物（C2/3 基本不允许，C1 有条件）。
- 焊料镀层不润湿/退润湿；镀通孔镀瘤/粉红环/镀铜空洞/成品镀层空洞/抬盘(可视)。
- 标记（蚀刻/丝印）位置尺寸可读；阻焊覆盖/对位/BGA/起泡/附着/波纹/**过孔盖油**（成品孔 Cl1/2≤1.0mm、Cl3≤0.65mm）。
- 线宽/线间距、外部环宽（见 2.1）、平整度见（表 2.11）。

## 2.3 内部可观察（第3章，切片）要点
- 介质空洞/裂纹、导体-孔对位、介质余隙、分层起泡、凹蚀/负凹蚀/除沾污、层间距、树脂回缩、pullaway。
- 蚀刻特性/悬出 overhang、表面铜厚、内层铜厚。
- 内层环宽(≥0.025mm C3)、抬盘、箔裂(C内层 / A/B/D外层)、镀层裂(E桶壁/F转角，全等级不允许)、镀瘤、孔壁铜厚、镀层空洞、芯吸、内层分离(C2/3不允许，C1单侧≤20%焊盘)、盲/埋孔填充(埋孔C2/3≥60%填料，C1可空)。
- 钻孔毛刺（不减小孔径/镀层即可）、钉头 nailheading（全等级可接受，仅工艺指示）。

# Part 3 · 三份标准怎么串联验收
1. **设计**：IPC-2221（本 skill 主体）定 Class/Level/Type 与设计值（比验收下限更宽）。
2. **采购/验收（性能）**：合同注明 IPC-6012E + Class + Type；按 表3-9/3-4~3-6/3-7/3-10/3-17/3-18 等逐项测。
3. **验收（外观/切片）**：按 IPC-A-600G 判"目标/合格/不合格"。
4. 冲突按优先级（合同>主图>性能规范>A-600）。
