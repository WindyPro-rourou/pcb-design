# 材料 / 表面处理 / 阻焊 / DFM（IPC-2221 第 4、5 章）

## 1. 基材选择三维度
- **结构强度**：先定义服役环境(振动/冲击/G 载荷/温湿度)；优先标准结构板材，避免验证成本与长交期。
- **电性能**：电气强度、Dk、Df、吸湿、水解稳定性（见表 4-1 / 6-2）。
- **环境性能**：按树脂体系查表 4-2（温度、吸湿等）。
> prepreg 一般与覆铜板同树脂/同增强型；具体流动度/凝胶时间/树脂含量是工艺参数，由板厂控制，通常不写进主图纸。

## 4. 阻焊（Solder Mask）
- 常用 IPC-SM-840；Class 3 用 Class H。
- 阻焊窗口余隙：**光成像 0–0.13mm**；**丝网印刷 0.4–0.5mm**。
- 熔化金属(喷锡/锡铅镀)上完全覆盖阻焊的单根导体宽 **≤1.3mm**；更宽须开"释放口"≥6.45mm²、网格 ≤6.35mm、重叠 ≤1.0mm。
- 过孔盖油(Tenting)：成品孔 ≤1.0mm(C1/2)/≤0.65mm(C3)；两面盖/填。
- 阻焊对位到孔/焊盘须满足主图纸注册要求；大面积无释放铜(>625mm²)建议加附着促进剂。

## 5. 三防漆 / 保形涂层 Conformal Coating
- 常用 IPC-CC-830。厚度：AR/ER/UR **0.03–0.13mm**，SR **0.05–0.21mm**，XY **0.01–0.05mm**。
- 类别：硅酮(耐温、易返修但耐磨差)、有机(电气/耐磨/耐溶剂好，≤125℃)、聚对二甲苯 Parylene(电气/阻隔极佳但贵、需真空)。
- 仅是有机蒸气屏障；无导体区域可不涂；板边一般不涂。

## 6. 丝印 / 标记
- 字高 **≥1.5mm**、线宽 **0.3mm**；清晰可辨。
- 不放在元件下方/被遮盖处/导电面/熔化金属或阻焊上。
- 固定信息(料号/版本/层号/极性)尽量做进底片；变动信息(序列号/日期码)用永久油墨/标签/激光。
- 液态丝印离可焊面留 0.4–0.5mm；避免油墨损伤可焊性。

## 7. 可制造性 DFM — Table 5-1 制造假设
- **板厚常用 0.8–2.4mm**（含铜）；过薄易翘、过厚层偏良率低、元件引脚可能不够长。
- **厚径比 ≤5:1 优先**。
- **对称结构**（上下半镜像，含芯厚/介质/平面/铜厚）→ 防翘曲。
- **铜间距 ≤0.1mm 或线宽 ≤0.1mm**：蚀刻液不流通/易损伤，尽量避开。
- **孔盘差 ≥0.6mm**；走线-焊盘连接处加泪滴。
- 面板尺寸常见 **460×610mm**；小板层对准更好；大板细特征考虑浮铜/分离层压。
- **翘曲(Bow&Twist)**：SMT 板 ≤**0.75%**，其他 ≤**1.5%**（IPC-TM-650 2.4.22 测）。
- 装配设备上限：自动插件 **450×450mm**、波峰焊 **400×open**、ICT **400×400mm**。
- 加强筋：沿连接器侧长度 >230mm 的板建议加，靠近连接器布置。
- 面板化(palletization)：每个小板基准要关联到面板基准，减少公差累积。

## 8. 组装/焊接耐温（元件选择）
- 波峰焊 **260℃/1min**；气相 **216℃/4min**；其他 SMT 回流 **216℃/≤1min**；底面 SMT 过波峰 **260℃/5s**。
- 不能承受者 → 手工焊或局部回流单独工序。

## 9. 投板前检查清单（DFM + 质量保证 IPC-2221 §12）
原理图 ERC → 原理图↔PCB 网络对比 → DRC（线宽/间距/孔/环宽/板边/阻焊/丝印/未连接）→ 3D 干涉
→ SI（阻抗/反射/串扰/等长/参考平面连续）→ PI（电源平面阻抗/去耦）→ DFM 对照板厂能力 → 出 Gerber/BOM/坐标。
> DRC 通过 ≠ 无问题：不能代替 ERC/网络对比/3D/SI/PI/DFM。
