# 焊盘 / 环宽 / 孔 / 过孔（IPC-2221 第 9 章 + 第 5 章相关）

## 1. 焊盘最小尺寸（最坏情况）

`Land(min) = a + 2b + c`
- **a** = 成品孔最大直径
- **b** = 最小环宽（见 §2）
- **c** = 标准制造余量（见 §3，含工具/工艺偏差）

> etchback（凹蚀）会削小内层支撑，**设计最小环宽不得小于最大允许凹蚀量**。

## 2. 最小环宽 Table 9-2（Class 1/2/3 通用设计最小值）

| 类型 | 最小环宽 |
|---|---|
| 内层支撑孔 Internal Supported | **0.03 mm** |
| 外层支撑孔 External Supported | **0.05 mm** |
| 外层非支撑孔 External Unsupported | **0.15 mm** |

- 内层环宽：钻完孔后孔壁到焊盘边缘的铜宽（最窄处）。
- 外层环宽：镀完孔后孔壁到焊盘边缘的铜宽。
- **Class 3 所有镀通孔必须有环宽**；Class 1/2 允许部分破环(breakout)但应尽量避免。
- 无环/局部环孔须买方预先批准并提供对应测试样。
- （IPC-6012 Table 3-7 另按 Class 定义验收环宽，具体数值查 6012 原表。）

## 6. 孔 / 过孔实践

- **厚径比（板厚 : 镀通孔直径）≤5:1 优先**：镀层更均匀、孔易清洗、钻孔漂移小、孔大抗孔壁开裂。
- **孔盘差**：焊盘至少比孔大 **0.6 mm**（Table 5-1，防破环）；大焊盘会挤占最小间距。
- **相邻孔残余基材 ≥0.5 mm**（结构强度）。
- 建议走线与焊盘连接处加**泪滴/圆角**，防开裂、增环宽余量。
- **热焊盘(Thermal Relief)**：仅对"需焊在大面积铜(地/电源/热)上的孔"；提供焊接热阻、缩短焊接时间；孔/盘/辐条(width)比例关键。
- **过孔盖油(Tenting)**：成品孔直径 **Class 1/2 ≤1.0mm、Class 3 ≤0.65mm**；更大需买卖双方约定。盖油/塞孔须两面都盖住或填满，防工艺液进入。
- **盲孔**应填/塞聚合物或阻焊，防止焊料进入（小孔进锡降低可靠性）。
- 盲孔加工两法：层压后从表面钻到内层再镀；或层压前钻表面到首/末埋层、镀通、图形化后再层压。埋孔只在内部层间，多用相邻两层。
- 过孔保护(Via Protection)、铜填孔/盖帽等高性能要求见 IPC-6012（cap plating、copper filled via、microvia target land 等）。

## 7. 焊盘形状 / 表面贴装
- 圆形焊盘最常用；允许"改形焊盘"(fillet/keyhole/角进) 增加焊盘面积（当允许破环时），但须满足载流。
- **SMT 焊盘**：设计须考虑制造余量、与元件的相对位置直接影响焊点；靠焊区"缩颈"降低热窃取；参见 IPC-SM-782。
- 扁平/压扁圆形引脚焊盘：见标准 Figure 8-16；Class 3 侧向悬出允许 ≤1/4 引脚直径；压扁厚度 ≥原直径 40%。
- **测试点**：可由过孔/宽导体/元件焊盘充当，须留足够探测面积、探测时不破坏连接；测试点不得有涂层（测后可涂）。
- **方向标记**：用特殊符号或焊盘形状标 pin1/极性，便于装配检验。
