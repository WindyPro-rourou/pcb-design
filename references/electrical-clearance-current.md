**>500V 计算**：取 301–500V 该列的值为基准，加上 (V−500)×该列每伏系数。
- 例 B1 600V：0.25 + (600−500)×0.0025 = 0.50 mm。
- 例 B2 800V：2.5 + (800−500)×0.005 = 4.0 mm。

**规则要点**
- 同层导体间距、层间(z 轴)间距、导电标记/安装硬件与导体间距，都按此表；能大尽量大。
- 高压 >200V（尤其 AC/脉冲）须考虑材料介电常数与电容分压效应。
- 不要只依赖涂层维持高表面电阻（潮湿/凝露会失效）；高阻/高压电路外层尽量拉开。
- 混合电压且需分开电测时，须在图上标注区域。

## 2. 载流 / 线宽 Figure 6-4

- 用"导体厚度-宽度 ↔ 电流 ↔ 温升"曲线查；图已含 **10% 电流降额**。
- **再降额 15%**：板厚 ≤0.8mm，或铜厚 ≥108µm(约3oz+)。
- 多根紧邻并联导线：等效截面积求和、等效电流求和后查图。
- 图未计入"功率器件附加热"；导体厚度不含非铜镀层。
- 工程常用拟合式（由曲线拟合，**非标准原文，仅速估**）：
  `I = k·ΔT^0.44·A^0.725`，A=线宽(mil)×铜厚(mil)，k=0.024(外层)/0.048(内层)。
  例：外层 10mil×1oz(1.37mil)、ΔT=10℃ → A≈13.7mil² → I≈0.024·10^0.44·13.7^0.725 ≈ 1.0A 量级。关键电源仍按图复核。

## 4. 导体定义 / 走线
- 最小成品线宽 ≥0.1mm；能大尽量大；线宽尽量均匀，可缩颈/加粗但不得违反最小宽度/间距。
- 走线尽量短；直线 X/Y/45° 方向优先（便于自动化）；**拐角内角 <90° 应倒圆或倒角**（禁锐角/直角蚀刻"酸角"）。
- 高速关注：源-负载-端接的连续布线、分支(stub)长度受控。
- 大量无功能铜作"电镀诱饵(plating thief)"可均匀镀层密度，但不得影响最小间距。
